# Python Keylogger

A simple keystroke logging tool built with Python and the pynput library.

## What it does
- Runs in the background and captures keyboard input in real time
- Logs all keystrokes to a text file (keyfile.txt)
- Records special keys like Enter, Shift, and Space in brackets

## Requirements
- Python 3.x
- pynput library

## Installation
pip install pynput

## How to run
python keylogger.py

## Usage
- Run the script
- Type anything — keystrokes will be saved to keyfile.txt
- Press Enter in the terminal to stop the program

- Python
- Event-driven programming
- File I/O
